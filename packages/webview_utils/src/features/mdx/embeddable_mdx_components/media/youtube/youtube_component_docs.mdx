## Youtube

Embed videos directly in your notes using the `<Youtube />{:tsx}` component.


### Example

````tsx
<Youtube 
    url="https://youtu.be/-7DvvDhyyNA"
    id="someOptionalId"
/>
````

````long-docs
With the optional id field provided, you can then link to timestamps within this video directly using the syntax `[My link content](video:someOptionalId@4:13)`, to link to 4 minutes and 13 seconds for example.

### Link Syntax

```md
[<Displayed text>](video:<video id>@<timestamp>)
```

````
