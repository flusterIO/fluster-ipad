# Conundrum: The Language

Conundrum grew out of an `.mdx` application once the additional parsers started to conflict with existing `.mdx` syntax, and for this reason, it's almost identical to `.mdx` apart from the additional features that it offers.

## Additional Features

### Horizontal Rule

Conundrum offers an additional horizontal-rule that accepts children using the following syntax.

```md
--- My text here ---
```

Will produce:

--- My text here ---

As with all Conundrum _children_, the horizontal-rule accepts any content that can go anywhere else, including math and other components:
